# 太空幸存者古早demo

一个浏览器里的无尽生存小游戏，保留两种可以独立打开的版本。

| 版本 | 入口 | 内容 |
| --- | --- | --- |
| 太空版 | [space/index.html](space/index.html) | 深色网格、几何角色和早期玩法，无音效 |
| 美术音效版 | [remix/index.html](remix/index.html) | 角色与敌人美术、两种场地、程序生成的背景音乐和战斗音效 |

## 运行

下载仓库，在仓库目录启动静态服务器：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8000/>，选择想玩的版本。不需要安装前端依赖或构建；游戏所需文件均在仓库内。因为使用 JavaScript 模块，请通过 HTTP 服务打开，不要直接双击 HTML。

## 操作

- 太空版：按住鼠标拖动，或在触屏上拖动；右上角按钮暂停。
- 美术音效版：按住左键向鼠标方向移动；长按 1.2 秒后松手可持续跟随，再左击停止。也支持 WASD、方向键和触屏拖动。
- 美术音效版：Esc 暂停；成长时点击选项，或按数字 1–4。底栏可切换外观、场地，开关声音和调节音量。
- 自动攻击敌人，拾取经验后选择成长，尽量生存更久。刷新页面重新开始，不保存进度。

这是一份早期 demo，未进行完整的平衡或长时间性能验证。太空版保留早期表现，修正了碰撞半径、敌弹标记及重复动画循环等基础问题。美术音效版的“原版”按钮只切换同局的表现，不会重置游戏。
